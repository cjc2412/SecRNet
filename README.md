# SecRNet

Official repository for **“Learning a Better Second-Order Network for EEG Decoding: A Covariance Pooling Method.”**

## Overview

SecRNet is an end-to-end second-order neural network for EEG decoding. It combines spatiotemporal feature extraction with attention-guided matrix square root covariance pooling and Log-Euclidean tangent-space classification. The model is evaluated on motor imagery (MI), steady-state visual evoked potential (SSVEP), and error-related negativity (ERN) paradigms.
